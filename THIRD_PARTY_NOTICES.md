# asm2dbsm2 – Third-Party Notices / Attribution

This distribution contains Python extension modules adapted from Matlab BSM2 and BSM2-GHG workflows, refactored for ASM2d-compatible stream vectors.

## Upstream BSM2 source attribution

Benchmark Simulation Model No. 2 (BSM2) by:

- Dr Ulf Jeppsson, IEA, Lund University, Sweden
- Lund University / IEA contributors including Christian Rosen and others
- IWA Task Group on Benchmarking of Control Strategies for WWTPs

Reference document:

- *Benchmark Simulation Model No 2 (BSM2)*, Dr Ulf Jeppsson, IEA, Lund University, Sweden, version September 2009/2011.
